# 🧮 Ejercicios de Recursividad en Python - Keytlen Mata

Implementación de 10 problemas clásicos resueltos exclusivamente con programación recursiva, desarrollada con fines académicos para demostrar dominio del paradigma de llamadas a función, gestión de pila de ejecución y diseño de casos base.

---

## 📖 Descripción
Este repositorio contiene la resolución de 10 ejercicios de recursividad en **Python 3.10+**. Cada función ha sido diseñada **sin utilizar estructuras iterativas** (`for`, `while`), respetando estrictamente el modelo recursivo con:
- ✅ Casos base bien definidos que garantizan terminación
- ✅ Pasos inductivos que reducen progresivamente el problema
- ✅ Tipado estático y documentación técnica integrada

---
